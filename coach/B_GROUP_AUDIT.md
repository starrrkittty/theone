## 本次优先完善

1. 补充真实可追溯来源：ACE 五类具体动作指导、WHO 内容、Fry 2003 研究摘要。检索按专家和动作变式筛选，避免深蹲口令误入其他专家。
2. 明确不同角度的含义：膝屈曲与骨段夹角、躯干相对水平/竖直、肘屈曲与上臂外展。未知定义不能确定纠错。
3. 程序核对相机平面、动作阶段、3D 标定声明、分类与关键点置信度、专项观测相关性。测量不充分必须 limited。
4. 为七类专家建立姿势关注项；输入缺少足部接触、肩髋踝关键点、脊柱形状或轨迹时明确不可评估，不补造观察。
5. 左右差值仅在同定义、同阶段及具备解释条件时计算，并声明其不是错误阈值或伤病判断。
6. 网页可选择每关节角度定义并单独检查测量条件；这个功能不依赖 API，也不会假装已经由模型完成评价。

## 科学证据边界

ACE 页面是公开教练指导，不能代替系统综述、个体评估或相机模型标定。Fry 研究摘要是7名受训男性的负重平行深蹲试验，观察力矩分布，没有验证通用安全角度或伤病发生率。WHO 指南是人群健康建议，不能验证深蹲/俯卧撑姿势角度。部分硬拉、推举、侧平板、平衡等变式仍只有项目检查表，应继续补充独立来源。

程序校验能保护测量值和引用来源，并不能证明模型文字推理全部正确。未接真实 Key，尚无真实模型质量验证。

## 下一阶段优先级

1. A/B 统一关节命名、三点定义、左右标记、角度零点、坐标系、投影平面、误差估计和事件时间；这是可靠角度指导的前提。
2. 加入每次重复的阶段序列：底部幅度、轨迹、节奏、组内稳定性和相机遮挡；每个指标必须有真实观测，不能用单帧替代。
3. 按变式制作专家审核病例：正确、常见偏差、低置信度、视角错误、疼痛、未知变式；接 API 后检查模型能否正确依据/拒判。
4. 建立参考条件化的角度规则：注明适用变式、人群、阶段、测量方法、来源、误差和审核人。未审核规则不启用，不能直接设置“膝角必须90°”等普遍标准。
5. 补带练状态机、动作观察历史、计划版本比较及结构化风险/疲劳记录，再完善持续性动态调整。
