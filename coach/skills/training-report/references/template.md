# Session Summary Template

- Session: date/time and duration
- Completed: exercise, sets, reps; list only recorded values
- Effort: submitted rating or "not recorded"
- Movement observations: cue, observation, confidence/limitations
- Recovery: submitted user check-in or "not recorded"
- Next session: conservative single-step suggestion based on recorded effort/recovery

Suggested data shape: `session_id`, `duration_minutes`, `completed_exercises`, `sets_completed`, `reps_completed`, `incomplete_targets`, `average_perceived_effort`, `movement_highlights`, `caution_observations`, `recovery_check`, `user_feedback`, `next_session_suggestion`, `disclaimer`.
