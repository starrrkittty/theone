# Phase Selection

Choose one phase using the supplied history, recovery and goal. Phase is one of:

- `adaptation`: new or returning trainee; learn comfortable patterns, short sessions, easy effort.
- `foundation`: consistent sessions with adequate recovery; establish repeatable full-body work.
- `specialized`: a goal-specific emphasis supported by training experience and recovery, with sustainable volume.
- `consolidation`: review, maintenance or reduced workload when adherence/recovery requires adjustment.

These are project planning categories, not scientifically validated durations. Do not automatically advance after a fixed number of weeks. Explain the evidence for the selected phase in `focus` and the review conditions in `review_note`.

Return exactly seven weekday entries. Rest days use `rest_or_easy_walk`. Training days must match the requested availability. For aerobic or mobility sessions use the same main-row contract: pattern, exercise_option, sets, reps (may describe minutes), effort_target. Warmup and cooldown must leave time for main training. Describe rest and pacing in effort_target so the full session fits the user's time.

If stored_reports/current_movement/latest_report are available in context, use them to explain changes from the previous plan. Without history, state that this is an initial plan. Do not invent adherence, progress, pain, or a prior phase. Injury notes require conservative limitations and professional review; do not prescribe rehabilitation.
