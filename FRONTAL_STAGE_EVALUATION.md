# Exercise-specific capture and independent stage evaluation

## Scope

Capture is full body, one exercising person, with an exercise-specific view.
Live and offline requests now use `capture_profile=exercise_view_v1`.
`GET /api/agent-a/capture-protocols` exposes the authoritative filming catalog.
Squat, pushup and plank prefer side view; curls prefer front view. Front squat
observations may assess projected bilateral tracking, but do not establish depth.
View estimates require 70% agreement over up to 600 ms and at least three samples.
Declared view is stored separately and never overrides the estimated view.
Legacy `frontal_v1` remains accepted for earlier captures.

The legacy skeletal diagnostic inputs remain `unspecified` for reproducibility.
The RepCount GIF demonstration is not a frontal acceptance benchmark. Do not use
its counting results as proof that frontal squat angles are accurate.

## Separate three evaluations

| Stage | Input | Independent reference | What to measure |
| --- | --- | --- | --- |
| A1 video to pose | RGB frames through selected pose model | Manually annotated image keypoints | Coverage, torso-normalized error, PCK, 2D projected angle error |
| A2 pose to JSON | Manually annotated/corrected landmark time series | Exercise/cycle labels and independently computed angles | Classification, count error, timestamps, units, missing-data handling, URDF/state round trip |
| B JSON to advice | Fixed reviewed movement JSON | Qualified exercise reviewer assessment | Evidence fidelity, unsupported claims, correct uncertainty handling, usefulness of guidance |

Use the same fixed inputs to compare model versions. Keep training/development
clips separate from validation/test clips and split by person where possible.
A1 reference points must not be another output of the same pose model. A2 tests
must not receive the target action as an inference hint. B's expected advice must
not be generated by the same evaluated model and treated as independent truth.

## Pose-stage evaluator

`tools/evaluate_pose_stage.py` compares the downloaded `video-landmarks.json`
against independent reference JSON of this shape:

```json
{
  "annotation_kind": "independent_manual_2d",
  "frames": [
    {
      "timestamp_ms": 0,
      "landmarks": []
    }
  ]
}
```

Replace the empty landmark array with exactly 33 image-normalized points in
MediaPipe index order. Mark unavailable reference points with visibility zero;
reference shoulder/hip points must be visible for normalization. Match exact
sampled media timestamps. Do not use wall-clock timestamps as video timestamps.
The reference schema describes annotation format; it does not certify its origin.

```powershell
& 'C:/Users/woshi/anaconda3/python.exe' tools/evaluate_pose_stage.py video-landmarks.json manual-reference.json --output pose-evaluation.json
```

The evaluator includes missing predictions in PCK failures, reports coverage
separately, and computes 2D projected angle MAE only where all three points are
visible. A low 2D angle error does not validate learned 3D world coordinates.
Penn Action 13-point references require an explicit joint-index mapping and time
alignment before use; duplicate invented joints must not become reference truth.

## Pose-to-JSON and B checks

Existing `tools/replay_evaluation.py --full-chain` and
`tools/evaluate_completed_sets.py` accept fixed landmark sequences. Supply held-out
manual/reference sequences to isolate A2 from MediaPipe. Evaluate motion/counts
against cycle labels; inspect raw and filtered angles, missing joints, parser
output, and source-specific included-angle versus bend-angle definitions.

For B, compare fixed reviewed JSON with A-generated JSON from the same clip. If B
fails on reviewed inputs it is a downstream issue; if only generated inputs fail,
inspect upstream fields and the adapter. Model B evaluation still requires an API
key and an independent expert reference. Local rule feedback is not AI validation.

## Anatomical limitations

Frontal views support image-plane symmetry and lateral tracking better than
sagittal flexion. MediaPipe world landmarks estimate depth without external
calibration. Accurate clinical/anatomical 3D angles cannot be guaranteed from
frontal RGB alone. The reduced URDF expresses measured hinge proxies, not the
entire anatomy. Parsing a self-consistent URDF and low forward-kinematic residual
validate internal conversion, not the accuracy of the original body measurement.
